# 0004. 定制代码目录隔离

- 状态：Accepted
- 日期：2026-07-28

## Context

本团队基于 yudao 二次开发并定制化交付。若定制代码与上游业务模块共用文件路径，每次 `upstream-sync` 合并上游更新时会产生大量冲突，抬高同步成本。

## Decision

定制代码统一置于 `apps/web-antd/src/views/custom/`，按客户或项目建立子目录（如 `custom/<客户>/`），避免与上游业务模块路径直接冲突。

## Consequences

- 正向：与上游路径物理隔离，显著降低同步冲突面。
- 代价：需团队纪律遵守目录约定。
- 后续：可在 CI 增加规则校验定制代码不越界（可选，按需）。
